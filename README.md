# 🚀 Landing Page Premium Dark Mode - Isaias Avila

Bienvenido a tu nueva landing page personalizada con estética "Dark Luxury" y color de acento Verde Neón (#22C55E). Esta web está diseñada para convertir visitantes en clientes destacando tus servicios de automatización con N8N y desarrollo web.

## 🎨 Sistema de Diseño

- **Modo:** Dark Luxury
- **Color Principal:** Verde Neón (`#22C55E`)
- **Tipografía:** 
  - Títulos: *Plus Jakarta Sans*
  - Cuerpo: *Inter*
  - Código/Tags: *JetBrains Mono*

## 📸 Imágenes Generadas por IA Incluidas

## 💡 Interacciones Destacadas

- **Flip Cards 3D:** Tarjetas interactivas en la sección de servicios. Hover en desktop y Tap en mobile.
- **Sistema de Partículas:** Partículas dinámicas sutiles en el fondo para una estética premium.
- **Glassmorphism:** Efectos de cristal translúcido en tarjetas métricas, servicios y navbar.
- **Animaciones al Scroll:** Los textos e imágenes revelan su presencia orgánicamente al desplazarse mediante Intersection Observer.
- **Contadores Animados:** Números que incrementan fluidamente enfatizando tus resultados asombrosos.

## 🛠️ Cómo Utilizarla

1. Todo el proyecto está contenido en la carpeta actual (`landigig_freelanzer`).
2. Abre el archivo `index.html` en tu navegador para previsualizar.
3. Puedes editar directamente el HTML para refinar tus textos.
4. Si quieres cambiar el color de acento en el futuro, solo ajusta la variable `--primary-500` en `styles.css`.
5. ¡Lista para subir a cualquier entorno estático como Netlify, Vercel o tu propio hosting!
